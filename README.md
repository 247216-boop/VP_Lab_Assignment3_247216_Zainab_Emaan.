# Certo Software Responsive Landing Page
**Visual Programming - Lab Assignment 3**

## Project Overview
A high-fidelity, pixel-perfect conversion of the Certo Software Figma design. This project demonstrates responsive web design principles using modern frontend technologies.

## Technologies Used
* **HTML5:** Semantic structure for SEO and accessibility.
* **CSS3:** Custom styling, variables, and media queries.
* **Bootstrap 5:** Grid system for responsive layout.

## Key Features
* **No JavaScript/C#:** Built strictly with HTML and CSS.
* **Responsive Breakpoints:** Optimized for 360px, 768px, and 1200px+.
* **Version Control:** Over 70+ commits documenting the build process.

## Folder Structure
* `/assets/css` - Custom stylesheets.
* `/assets/images` - Optimized project assets.
* `index.html` - Main entry point.
